KEY FILES & THEIR PURPOSE:
═══════════════════════════════════════════════════════════════════════

📌 ENTRY POINTS:
  • main.py                → Run the Flask app (python main.py)
  • create_db.py          → Initialize database (python create_db.py)

📌 CORE LOGIC:
  • app/__init__.py        → Flask app factory, blueprints registration
  • app/models.py          → Database models (User, Question, Category, Attempt, etc)
  • app/config.py          → Configuration (SQLite DB path, SECRET_KEY)

📌 ROUTES & MODULES:
  • app/auth/routes.py     → Login/Register/Logout endpoints
  • app/quiz/routes.py     → Quiz flow (category→difficulty→questions→results)
  • app/admin/routes.py    → Admin panel (question/user CRUD, dashboard)

📌 TEMPLATES & STYLING:
  • app/static/css/professional.css   → Main theme (professional BootstrapMade-inspired)
  • app/templates/base.html           → Navbar & layout wrapper
  • app/templates/auth/*.html         → Login/Register centered forms
  • app/templates/quiz/*.html         → Quiz user flow
  • app/templates/admin/*.html        → Admin dashboard & management

📌 SETUP & DOCUMENTATION:
  • requirements.txt       → Python dependencies
  • README_RUN.md          → Setup & run instructions for partner
  • generate_run_guide_pdf.py → Converts README_RUN.md to PDF

DATABASE STRUCTURE:
═══════════════════════════════════════════════════════════════════════

User (id, username, email, password_hash, role)
  └── Attempt (id, user_id, score, total, category_id, difficulty, created_at)
      └── AttemptAnswer (id, attempt_id, question_id, chosen_option, correct)

Category (id, name)
  └── Question (id, text, option1-4, correct_option, difficulty, category_id, explanation)

URLS & ENDPOINTS:
═══════════════════════════════════════════════════════════════════════

USER PAGES:
  GET  /                          → Home page
  GET  /auth/login                → Login form
  POST /auth/login                → Process login
  GET  /auth/register             → Register form
  POST /auth/register             → Create new user
  GET  /auth/logout               → Logout user

QUIZ PAGES:
  GET  /quiz/select               → Category selection (user)
  GET  /quiz/start/<cat_id>       → Difficulty selection
  GET  /quiz/start/<cat_id>/<diff> → Start quiz
  GET  /quiz/question/<q_id>      → Display question
  POST /quiz/question/<q_id>      → Submit answer
  GET  /quiz/result               → Show results

ADMIN PAGES (login required + is_admin):
  GET  /admin                     → Dashboard (questions by category)
  GET  /admin/users               → Users list
  GET  /admin/user/new            → Create user form
  POST /admin/user/new            → Save new user
  GET  /admin/user/edit/<id>      → Edit user form
  POST /admin/user/edit/<id>      → Save user changes
  POST /admin/user/delete/<id>    → Delete user

  GET  /admin/categories          → Manage categories
  POST /admin/categories          → Add category
  
  GET  /admin/question/new        → Create question form
  POST /admin/question/new        → Save new question
  GET  /admin/question/edit/<id>  → Edit question form
  POST /admin/question/edit/<id>  → Save question changes
  POST /admin/question/delete/<id> → Delete question
  
  GET  /admin/questions/bulk-add  → Bulk import form
  POST /admin/questions/bulk-add  → Import multiple questions
